1 Contexte & Problématique

Le Problème

À Douala, comme dans la plupart des grandes villes camerounaises, trouver un artisan compétent et fiable est un parcours semé d'embûches. Les particuliers utilisent principalement Facebook, WhatsApp ou le bouche-à-oreille, méthodes qui exposent à trois risques majeurs :

  • L'escroquerie financière : avance non remboursée, travaux non réalisés
  • L'incompétence technique : absence de qualification vérifiable
  • Le manque de réactivité : artisans injoignables, délais non respectés

La Solution : ARTISAN-237

ARTISAN-237 est une plateforme numérique qui met en relation les particuliers et les artisans qualifiés à Douala. Elle repose sur trois piliers fondamentaux :

🔒
Escrow Stripe
Paiement séquestré jusqu'à validation des travaux
🤖
IA Random Forest
Recommandation intelligente des artisans
🛡️
KYC Didit
Vérification d'identité obligatoire

Objectifs Académiques

Ce projet a été conçu pour démontrer :

  • Une maîtrise des architectures logicielles modernes (Monorepo, Microservices)
  • Une utilisation pertinente de l'IA (Random Forest pour la recommandation)
  • Une intégration de systèmes de paiement sécurisés (Stripe Escrow)
  • Une application Mobile First optimisée pour les réseaux 3G/4G
  • Une plateforme crédible, prête pour une mise en production réelle

7 Trust Engine — Moteur de Confiance

Le Trust Engine est le cœur de la plateforme. Il calcule 4 scores qui déterminent la fiabilité d'un artisan. Implémenté dans trust-engine.service.ts.

Les 4 Scores

✅ Verification Score (VS)

Pondération : 25% du Trust Score final

Basé sur : KYC validé (60%), Email vérifié (20%), Téléphone vérifié (20%)

VS = (isKycVerified × 60) + (isEmailVerified × 20) + (isPhoneVerified × 20)

⭐ Reliability Score (RS)

Pondération : 45% du Trust Score final

Basé sur : Taux de complétion (50%), Note moyenne (50%)

RS = (jobsCompleted / totalJobs × 50) + (rating / 5 × 50)

📈 Experience Score (ES)

Pondération : 20% du Trust Score final

Basé sur : Jobs terminés, Ancienneté, Volume d'activité

ES = min(totalJobs / 100 × 40 + experienceYears × 10, 100)

⚡ Response Score (RPS)

Pondération : 10% du Trust Score final

Basé sur : Temps de réponse moyen aux devis

RPS = max(0, 100 - avgResponseTimeMin × 2)

Formule Finale

Trust Score = (VS × 0.25) + (RS × 0.45) + (ES × 0.20) + (RPS × 0.10)

Le Trust Score est affiché sur le profil de l'artisan, dans les résultats de recherche, et sur le dashboard artisan. Il est recalculé à chaque changement de statut de Job ou de note.

8 Sécurité & Authentification

Architecture de Sécurité

// Middleware Next.js (Edge Runtime) — apps/web/middleware.ts
Request → Check cookie 'session' → Si absent → Redirect /login
                                              → Si présent → Laisse passer

// Guards NestJS — apps/api/src/common/guards/
JwtAuthGuard : Vérifie le token JWT dans le header Authorization
RolesGuard : Vérifie le rôle (CLIENT | ARTISAN | ADMIN) via @Roles() decorator

// Exemple :
@Roles(Role.ADMIN)
@UseGuards(JwtAuthGuard, RolesGuard)
@Get("users")
async getUsers() { ... }

Flux de Connexion

1. Utilisateur saisit email + mot de passe sur /login
2. POST /api/v1/auth/login → NestJS vérifie les credentials (bcrypt)
3. Si OK → { accessToken } + cookie httpOnly (refreshToken)
4. Frontend stocke accessToken dans localStorage + cookie 'session'
5. router.push('/client') → middleware lit 'session' → laisse passer
6. Le rôle est extrait du JWT (payload.role) pour la redirection

11 Plan de Soutenance Académique

Introduction (2 min)

L'accroche : "Aujourd'hui à Douala, trouver un bon plombier sur Facebook est un pari risqué. L'artisan peut être incompétent, et vous risquez de perdre votre avance financière."

Présenter le problème : arnaques, absence de traçabilité, difficulté à trouver le bon professionnel.

Montrer un écran WhatsApp d'une conversation type pour illustrer.

Démonstration Phase 1 : La Magie de l'IA (5 min)

  • Ouvrir l'application côté Client sur mobile
  • Chercher "Électricien à Logbaba"
  • Point clé : La liste n'est pas alphabétique. Le premier résultat affiche "⭐ Match IA 94%"
  • Montrer le badge IA, cliquer pour voir l'explication : "À 2km, Note de 4.8/5, Répond en 15 min"
  • Expliquer brièvement le Random Forest : 59% note, 16% expérience, 8% réactivité
  • Montrer l'écran d'administration /admin/ai-demo pour le pipeline complet

Démonstration Phase 2 : Le Workflow Sécurisé (5 min)

  • Demander un devis à l'artisan recommandé
  • Basculer sur l'écran Artisan (split screen ou deuxième onglet)
  • L'artisan reçoit une notification, répond avec un devis à "15,000 FCFA"
  • Le client accepte le devis
  • Point clé : L'écran de paiement Stripe apparaît. L'argent est débité mais pas envoyé à l'artisan — il est sur un compte séquestre (Escrow).
  • Montrer le dashboard client : "120,000 FCFA protégés"

Démonstration Phase 3 : Libération & Trust Score (3 min)

  • Marquer le Job comme terminé
  • Cliquer sur "Libérer les fonds"
  • Noter 5 étoiles
  • Point clé : Le profil de l'artisan voit son Trust Score augmenter en temps réel
  • Montrer les 4 scores (VS, RS, ES, RPS) et leur calcul

Conclusion (1 min)

"Une stack technologique moderne — Next.js, NestJS, FastAPI, PostgreSQL — au service d'un vrai problème local. L'Intelligence Artificielle n'est pas un gadget : elle améliore concrètement la confiance, la découverte et la rapidité."
